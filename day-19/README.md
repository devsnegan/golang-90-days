## Important Concepts

- A struct groups related fields into one type.
- Use `type` to define a struct.
- Use `.` to access or update fields.
- Keyed literals specify field names.
- Unkeyed literals follow field declaration order.
- Uninitialized struct fields receive their zero values.
- Structs can contain other structs.

## Learning Goal

Understand how to create custom data types
and organize related information using structs.
