# 🚀 90 Days of Golang Mastery

Welcome to my **90 Days of Golang Mastery** journey.

This repository contains my daily learning, coding practice, exercises, projects, and notes as I progress from **Go fundamentals to production-ready backend development**.

The goal is not just to learn Go syntax, but to understand how Go works internally and build real-world applications using Go.

# 💻 Running the Code

Clone the repository:

```bash
git clone https://github.com/devsnegan/golang-90-days.git
```

Move into the project:

```bash
cd golang-90-days
```

Run a specific day:

```bash
go run ./day-01
```

Run an exercise:

```bash
go run ./day-01/exercises/exercise-01
```

Run all tests:

```bash
go test ./...
```

Format Go code:

```bash
go fmt ./...
```
